## Worum geht es?

Eine kuratierte, wöchentlich aktualisierte Liste der 1.275 E-Commerce-Actors, die tatsächlich genutzt werden, ausgewählt aus den 15.642 Actors der Kategorie E-commerce im Apify Store, plus Tools für Amazon.de, Otto, Kaufland, idealo und Shops in Deutschland, Österreich und der Schweiz. Actors, die in den letzten 30 Tagen niemand gestartet hat, fliegen raus, und jeder ist nach Shop oder Aufgabe einsortiert. So finden Sie in Sekunden ein Tool für Produktrecherche, Preisbeobachtung, Bewertungsanalyse oder Dropshipping.

Jeder Eintrag ist ein gehostetes Cloud-Tool (ein „Actor“) auf der Apify-Plattform: öffnen, Eingabe ausfüllen, auf Start klicken und die Ergebnisse als JSON, CSV oder Excel exportieren, oder per Apify API aus dem eigenen Code aufrufen. Jedes neue Konto erhält ein kostenloses Monatsguthaben, genug, um die meisten dieser Actors ohne Kosten zu testen.

> Titel und Beschreibungen der Actors stammen unverändert aus dem Apify Store und sind meist auf Englisch. Die Eingabeformulare akzeptieren Suchbegriffe auf Deutsch.

## So wählen Sie den richtigen Actor

- **Nutzer pro Monat** ist das beste Signal: Es zählt verschiedene Personen, die den Actor in den letzten 30 Tagen gestartet haben, verlassene Tools rutschen also nach unten.
- **Bewertung** stammt aus den Rezensionen im Apify Store. 4,5 oder mehr bei Dutzenden Bewertungen spricht für verlässliche Daten.
- **Preismodell** unterscheidet sich je nach Actor (pro Ergebnis, pro Ereignis oder Monatsmiete). Der aktuelle Preis steht immer auf der Seite des Actors, vergleichen Sie dort vor einem großen Lauf.
- **Erst klein testen.** Begrenzen Sie die Eingabe auf 10 oder 20 Ergebnisse, prüfen Sie die benötigten Felder und skalieren Sie dann.

## Häufige Fragen

### Wie überwache ich Preise auf idealo oder Amazon.de?

Im Abschnitt Amazon.de, Otto, Kaufland und DACH-Shops sowie unter Preisvergleich finden Sie die meistgenutzten Tools. Planen Sie einen Actor für tägliche Läufe ein und exportieren Sie die Preise nach Google Sheets.

### Kann ich Wettbewerberpreise automatisch beobachten?

Ja. Jeder Produkt- oder Preis-Actor lässt sich täglich planen, und der Abschnitt Preisvergleich enthält Tools, die Veränderungen über die Zeit verfolgen.

### Ist das Scrapen von Produktdaten legal?

Öffentlich sichtbare Produkt- und Preisdaten zu erheben ist gängige Praxis. Prüfen Sie trotzdem die Nutzungsbedingungen der Website und das geltende Recht, und erheben Sie keine personenbezogenen Daten, die Sie nicht brauchen (DSGVO).

### Brauche ich eigene Proxys oder Server?

Nein. Die Actors laufen in der Apify-Cloud und kümmern sich um Proxys, Browser und Anti-Bot-Schutz.

### Wie oft wird die Liste aktualisiert?

Eine GitHub Action baut sie jede Woche aus der öffentlichen Apify-Store-API neu auf. Neue Actors erscheinen, verwaiste fallen automatisch heraus.

### Kann ich meinen eigenen Actor hinzufügen?

Veröffentlichen Sie ihn im Apify Store in der Kategorie E-commerce. Sobald er genutzt wird, landet er beim nächsten wöchentlichen Update in der Liste. Kein Pull Request nötig.
